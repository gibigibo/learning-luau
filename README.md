# Learning Luau

I'm Daniel. I'm learning to code Roblox games in Luau, from zero, and this repo is where I write down how it's going.

## How I learn

- I learn by writing code and experimenting in Roblox Studio, not by copy-pasting tutorial code.
- I learn with the help of Claude and Roblox's official documentation, mainly the [Coding fundamentals](https://create.roblox.com/docs/tutorials/fundamentals/coding-1/coding-fundamentals) series.
